Activity 4: Programming with Sensors

Goal: Write and test code that reads an input and controls an output motor.

Input: The angle of one motor (the handle).

Output: The speed and direction of a second motor.

Worked with Evan Burns

We were assigned one motor as the input and another motor as the output. Evan Burns and I decided to replicate the MTA subway speed control. We used the angle of one motor as the input. The more it turned clockwise or counterclockwise, the faster the other motor rotated. The direction of the other motor also corresponds to the way the handle is turned.

Code

# Setup: Input motor on port C; output motor on port D.
from hub import port
import runloop
import motor

# Turning C this far gives D its maximum speed.
FULL_SPEED_TURN_DEGREES = 90

# Maximum speed for a Large motor, in degrees per second.
# If D is a Small or Medium motor, use its supported maximum instead.
MAX_OUTPUT_SPEED = 2000

async def main():
    # Treat motor C's current position as the stop position.
    motor.reset_relative_position(port.C, 0)

    # Continuously match motor D's speed to motor C's position.
    while True:
        input_degrees = motor.relative_position(port.C)

        # Limit the input to 90 degrees in either direction.
        if input_degrees > FULL_SPEED_TURN_DEGREES:
            input_degrees = FULL_SPEED_TURN_DEGREES
        elif input_degrees < -FULL_SPEED_TURN_DEGREES:
            input_degrees = -FULL_SPEED_TURN_DEGREES

        # Positive and negative positions produce opposite directions.
        output_speed = int(
            input_degrees * MAX_OUTPUT_SPEED / FULL_SPEED_TURN_DEGREES
        )

        # Stop at the starting position; otherwise update D's speed.
        if output_speed == 0:
            motor.stop(port.D)
        else:
            motor.run(port.D, output_speed)

        # Allow the hub to check the input again shortly.
        await runloop.sleep_ms(20)

runloop.run(main())
