Project 7: Draw a Square

At a glance

Goal: Attach a pen to the simple car and use its functions to draw a square.

Result: The redesigned car, with the pen placed between its wheels, drew a square.

Key takeaway: Placing the pen between the wheels let the existing rotation function stay the same, so the redesign changed the car instead of the code.

The Problem

I attached a pen to the simple car and used its functions to draw a perfect square. I realized that the car needed to be redesigned. If the pen were attached elsewhere on the car, I would have needed to program the car to rotate around the pen. The forward movement functions did not need to change; the rotation did.

The Redesign

Instead of reprogramming the rotation function to pivot around the marker, I redesigned the car by placing the pen between the two wheels. This meant the existing rotation function could stay the same, because the car already rotated around a point between its wheels. (see Final Design)

Keeping the Pen Centered

One challenge was keeping the pen exactly between the two wheels. I used a rubber-band arrangement to hold it in place and used building-block panels as an anchor rather than attaching the pen directly to a smooth surface. I still had to adjust the panel. It is not perfectly centered because the tip of the marker is not centered on the pen itself. (see Result and Demo Video)

Code: Drawing a Perfect Square

# Setup: left wheel motor on port D, right wheel motor on port C.
from hub import port, motion_sensor
import runloop
import motor_pair

# Measure your wheel diameter and update this value if needed.
WHEEL_DIAMETER_CM = 5.6
SQUARE_SIDE_CM = 10

# Speeds are in motor degrees per second; run_time is in milliseconds.
run_time = 2000
SLOW_SPEED = 125
FAST_SPEED = 1000
TURN_SPEED = 150

# Convert travel distance into the wheel rotation needed to cover it.
def distance_to_motor_degrees(distance_cm):
    wheel_circumference_cm = WHEEL_DIAMETER_CM * 3.14
    return int(distance_cm / wheel_circumference_cm * 360)

# Each straight-driving function takes a positive distance in centimeters.
async def move_forward_slow(distance_cm):
    wheel_degrees = distance_to_motor_degrees(distance_cm)
    await motor_pair.move_for_degrees(
        motor_pair.PAIR_1, wheel_degrees, 0, velocity=SLOW_SPEED
    )

async def move_forward_fast(distance_cm):
    wheel_degrees = distance_to_motor_degrees(distance_cm)
    await motor_pair.move_for_degrees(
        motor_pair.PAIR_1, wheel_degrees, 0, velocity=FAST_SPEED
    )

async def move_backward_slow(distance_cm):
    wheel_degrees = distance_to_motor_degrees(distance_cm)
    await motor_pair.move_for_degrees(
        motor_pair.PAIR_1, -wheel_degrees, 0, velocity=SLOW_SPEED
    )

async def move_backward_fast(distance_cm):
    wheel_degrees = distance_to_motor_degrees(distance_cm)
    await motor_pair.move_for_degrees(
        motor_pair.PAIR_1, -wheel_degrees, 0, velocity=FAST_SPEED
    )

async def spin_cc(angle):
    # Yaw is measured in tenths of a degree.
    target_yaw = abs(angle) * 10
    motion_sensor.reset_yaw(0)
    await runloop.sleep_ms(100)

    # Opposite wheel speeds rotate the car in place.
    motor_pair.move_tank(motor_pair.PAIR_1, -TURN_SPEED, TURN_SPEED)

    while abs(motion_sensor.tilt_angles()[0]) < target_yaw:
        await runloop.sleep_ms(5)

    motor_pair.stop(motor_pair.PAIR_1)

async def spin_c(angle):
    target_yaw = abs(angle) * 10
    motion_sensor.reset_yaw(0)
    await runloop.sleep_ms(100)

    motor_pair.move_tank(motor_pair.PAIR_1, TURN_SPEED, -TURN_SPEED)

    while abs(motion_sensor.tilt_angles()[0]) < target_yaw:
        await runloop.sleep_ms(5)

    motor_pair.stop(motor_pair.PAIR_1)

# These arc functions remain time-based.
async def small_arc():
    await motor_pair.move_for_time(
        motor_pair.PAIR_1, run_time, 70, velocity=FAST_SPEED
    )

async def big_arc():
    await motor_pair.move_for_time(
        motor_pair.PAIR_1, run_time, 30, velocity=FAST_SPEED
    )

async def draw_square():
    # Draw four equal sides, turning between them.
    for side in range(4):
        await move_forward_slow(SQUARE_SIDE_CM)
        if side < 3:
            await spin_c(90)


async def main():
    # Pair the left motor first and the right motor second.
    motor_pair.pair(motor_pair.PAIR_1, port.D, port.C)

    # Draw the square. To test one move instead, replace this call.
    await draw_square()

    # Free the motor ports when the drawing is finished.
    motor_pair.unpair(motor_pair.PAIR_1)

runloop.run(main())
