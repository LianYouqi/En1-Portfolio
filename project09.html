Project 9: Robotic Arm

June 2024

At a glance

Goal: Design an autonomous robotic arm capable of transporting a ping-pong ball from one place to another.

Result: A crane-like claw captures the ping-pong ball, and the arm repeats a color-triggered sequence of lowering, rotating, lifting, and rotating back.

Key takeaway: Gears of the same size did not attach nicely in the LEGO set, which pushed me to a second claw design that worked surprisingly well.

The Challenge

Design an autonomous robotic arm capable of transporting a ping-pong ball from one place to another.

Constraints: Movement is triggered by the ball being placed on the color sensor, and the arm returns to its initial position to wait for a new ball trigger.

Design Process

Attempt 1: Two connected gears

My initial approach was using claws to grip the ping-pong ball, and a motor that spins or lifts the ball as the means of transport. I focused on designing the claw because that seemed to be the most challenging part of the project. My initial idea was to use two gears connected to each other, but gears of the same size aren't designed to be attached nicely to each other on the LEGO set. I could use one 28-tooth gear and one 36-tooth gear, but that looked ugly.

Attempt 2: Crane-like claw

My second attempt actually worked surprisingly well. [this part] and [the crane-like claw] perfectly captured the ping-pong ball. With enough downward velocity, it shifts the ping-pong ball into a nice position.

Programming

From then on, my focus shifted to refining the programming of the robotic arm's behavior. There are five steps:

  1. Detect color change.
  2. Lower the arm to grip the ball.
  3. Rotate 180° counterclockwise.
  4. Lift the arm to release the ball.
  5. Rotate 180° clockwise.

Then the sequence repeats.

Color Sensor Robotic Arm Code

# Setup: Color Sensor on E, large motor on F,
# medium lift motors on D and B.
from hub import port
import runloop
import color
import color_sensor
import motor
import motor_pair

# Speeds are in degrees per second; angles are in motor degrees.
LARGE_MOTOR_INITIAL_SPEED = 180
LARGE_MOTOR_RETURN_SPEED = 180
LIFT_SPEED = 1050
LOWER_SPEED = 1050
LIFT_ANGLE = 550

async def spin_large_motor(speed, direction):
    # Choose the direction for the large motor's 180-degree turn.
    if direction == "clockwise":
        motor_degrees = 180
    else:
        motor_degrees = -180

    await motor.run_for_degrees(port.F, motor_degrees, speed)

async def lift(speed, angle):
    # Pair the lift motors, complete the move, then free their ports.
    motor_pair.pair(motor_pair.PAIR_1, port.D, port.B)
    await motor_pair.move_tank_for_degrees(
        motor_pair.PAIR_1, angle, speed, speed
    )
    motor_pair.unpair(motor_pair.PAIR_1)

async def lower(speed, angle):
    # Pair the lift motors, complete the move, then free their ports.
    motor_pair.pair(motor_pair.PAIR_1, port.D, port.B)
    await motor_pair.move_tank_for_degrees(
        motor_pair.PAIR_1, angle, -speed, -speed
    )
    motor_pair.unpair(motor_pair.PAIR_1)

async def main():
    # Remember the color present when the program starts.
    previous_color = color_sensor.color(port.E)

    while True:
        # Check for one new recognized color.
        current_color = color_sensor.color(port.E)

        if current_color != color.UNKNOWN and current_color != previous_color:
            print("New color detected:", current_color)

            # Finish every step before checking the sensor again.
            await runloop.sleep_ms(1000)
            await lower(LOWER_SPEED, LIFT_ANGLE)
            await spin_large_motor(LARGE_MOTOR_INITIAL_SPEED, "counterclockwise")
            await lift(LIFT_SPEED, LIFT_ANGLE)
            await spin_large_motor(LARGE_MOTOR_RETURN_SPEED, "clockwise")

            # Treat the color present after the sequence as the new reference.
            # This prevents a change during movement from triggering another run.
            previous_color = color_sensor.color(port.E)

        # Pause briefly between sensor checks.
        await runloop.sleep_ms(50)

runloop.run(main())
