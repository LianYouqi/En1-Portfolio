Project 10: Haunted House

October 30, 2026

At a glance

Goal: Create an interactive Halloween haunted house feature.

Result: A bait-scare contraption that uses hub-to-hub communication, with a light-up toy skull as the scare.

Prepping for the Haunted House

There were four options: Cardboard and Craft Creations, Scissor Lifts, Pulley and Drops, or Hub-to-Hub Communication. I chose Cardboard and Craft Creations.

I designed a coffin, but I ran out of class time to attach the hinges.

The Challenge

For our haunted house project, we were tasked with building an interactive feature that was part of Tufts' annual Haunted House on October 30, 2026.

Design Process

The concept: Bait and hub-to-hub communication

Our initial idea was to use some sort of bait, and we would use hub-to-hub communication to broadcast a signal to another hub (Hub B) that would act as our main scaring mechanism.

Individual Part 1

Individual Part 2

Ideas we thought about

We thought about using balloons and constructing a mechanism for Hub B to pop it. The idea was scrapped because it required reloading.

We also tried to find an alternative to balloons using plates and having them slam against each other. That idea was also scrapped. The noise wasn't loud, and the motor's torque was not strong enough.

It was hard finding an idea we all agreed upon. In the end, we just wanted to build a prototype that works and scale up from there via hub-to-hub communication.

Final design: Light-up toy skull

Eventually, we settled on using one of the toy skulls that light up. Hub A broadcasts a signal once someone takes the bait. Once Hub B receives the signal, it opens up the gates and the skull gets activated.

Final design running

Reflection

We didn't have time to scale up our design because we had trouble concealing the skull. Our design with the gates could have been thought out better.

Other ideas or components for our design included a one-time-use balloon, a vibrating box, and real audio.

Code for Hub A

# Hub A setup: Medium Motor on port A; Hub B listens for "!F".
from spikecomm import Beacon
from hub import port, sound
import runloop
import motor

HOME_ANGLE = 180
PULL_THRESHOLD = 15
RETURN_SPEED = 1050
RETURN_DELAY_MS = 300
CHECK_INTERVAL_MS = 20
READY_BROADCAST_INTERVAL_MS = 100

fire_beacon = Beacon("!F")

def broadcast_fire_state(value):
    # The message protocol is 0 = ready, 1 = pull detected.
    fire_beacon.broadcast(value)

async def return_home():
    # Leave a short pause before the motor moves back.
    await runloop.sleep_ms(RETURN_DELAY_MS)
    await motor.run_to_absolute_position(port.A, HOME_ANGLE, RETURN_SPEED)

async def handle_pull():
    broadcast_fire_state(1)
    print("Pull detected: broadcast 1")
    await return_home()

async def watch_for_pulls():
    # Measure each pull from the position reached after the last return.
    home_position = motor.relative_position(port.A)
    time_since_ready_broadcast_ms = READY_BROADCAST_INTERVAL_MS

    while True:
        current_position = motor.relative_position(port.A)

        if abs(current_position - home_position) >= PULL_THRESHOLD:
            await handle_pull()
            home_position = motor.relative_position(port.A)

            # Hub B must see 0 before it can accept another 1.
            broadcast_fire_state(0)
            time_since_ready_broadcast_ms = 0
        elif time_since_ready_broadcast_ms >= READY_BROADCAST_INTERVAL_MS:
            broadcast_fire_state(0)
            time_since_ready_broadcast_ms = 0

        await runloop.sleep_ms(CHECK_INTERVAL_MS)
        time_since_ready_broadcast_ms += CHECK_INTERVAL_MS

async def main():
    await return_home()
    await watch_for_pulls()

runloop.run(main())

Code for Hub B

# Hub B setup: gate motors on ports E and F.
# Hub A broadcasts 0 when ready and 1 when a pull is detected.
from spikecomm import Scanner
from hub import port
import runloop
import motor
import motor_pair

# Original values in the comments
GATE_SPEED = 495
GATE_ANGLE = 80 # 55
WAIT_TIME_MS = 5000 # 5000
CHECK_INTERVAL_MS = 20
D_MOTOR_SPEED = 660

fire_received = False
armed = False
gate_busy = False

def on_fire(values):
    global fire_received, armed

    # Ignore messages while the gate moves, and reject unexpected formats.
    if gate_busy or len(values) != 1:
        return

    if values[0] == 0:
        # A ready message permits the next pull to trigger the gate.
        armed = True
    elif values[0] == 1 and armed:
        # Disarm immediately so repeated reports of 1 cannot retrigger it.
        armed = False
        fire_received = True
        print("Pull signal accepted")

async def wait_for_pull():
    global fire_received

    while not fire_received:
        await runloop.sleep_ms(CHECK_INTERVAL_MS)

    fire_received = False

async def move_gate(degrees):
    # Both gate motors move together; the sign selects open or close.
    if degrees > 0:
        gate_speed = GATE_SPEED
    else:
        gate_speed = -GATE_SPEED

    await motor_pair.move_tank_for_degrees(
        motor_pair.PAIR_1, abs(degrees), gate_speed, gate_speed
    )
async def click_button():
    await motor.run_for_degrees(port.D, 55, D_MOTOR_SPEED)
    await motor.run_for_degrees(port.D, -55, D_MOTOR_SPEED)

async def run_gate_sequence():
    motor_pair.pair(motor_pair.PAIR_1, port.E, port.F)

    await move_gate(GATE_ANGLE)
    await click_button()

    await runloop.sleep_ms(WAIT_TIME_MS)

    await move_gate(-GATE_ANGLE)
    await click_button()

    motor_pair.unpair(motor_pair.PAIR_1)

async def main():
    global armed, gate_busy

    scanner = Scanner("!F")
    scanner.listen(on_fire)
    print("Waiting for 0, then 1")

    while True:
        await wait_for_pull()

        gate_busy = True
        await run_gate_sequence()

        # Require a ready message received after the gate closes.
        armed = False
        gate_busy = False
        print("Gate closed; waiting for 0, then 1")

runloop.run(main())
