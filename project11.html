Project 11: High or Low (Supervised Machine Learning)

November 2, 2026

At a glance

Goal: Build a device that uses supervised classification to identify “high” vs. “low” heights.

Result: A device that stores distance sensor and motor position pairs, then uses the K-nearest-neighbor algorithm (K = 3) to point the motor at the matching position.

The Challenge

Build a device that uses supervised classification to identify “high” vs. “low” heights, learning from stored distance sensor and motor position pairs and then using the nearest neighbor to point the motor at the matching label.

How It Works

The hardware

In this project, I implemented the K-nearest-neighbor algorithm to classify between “high” and “low” heights. My robot uses a force sensor, a medium motor, a distance sensor, and the buttons on the hub. The medium motor is responsible for labeling the distance data points that the distance sensor gathers. The more I turned the motor to the right, the closer the object is to my robot, and vice versa.

Back view

Side view

Training mode

I programmed the force sensor to gather the data. Pressing it with more than 6 N saves the current distance reading together with the motor's angle as one data point, and then the medium motor returns to the absolute position (0°).

Prediction mode

Next, pressing either arrow button on the hub transitions the robot into prediction mode. The robot reads the distance sensor, finds the three saved data points with the closest distances, averages their motor angles, and turns the medium motor to that angle. Pressing either arrow button again returns the robot to training mode, and the saved data points are kept.

High or Low Program Code

# Setup: Distance Sensor on C, Force Sensor on B, motor on E.
from hub import port, button
import runloop
import motor
import distance_sensor
import force_sensor

RETURN_SPEED = 300       # Degrees per second.
PREDICTION_SPEED = 300   # Degrees per second.
NEIGHBOR_COUNT = 3
FORCE_THRESHOLD = 60     # Decinewtons: 60 = 6 N.

def predict_motor_position(distance_mm, training_samples):
    # Find how far each saved distance is from the current reading.
    nearby_samples = []
    for saved_distance, saved_angle in training_samples:
        difference = abs(saved_distance - distance_mm)
        nearby_samples.append((difference, saved_angle))

    # Put the closest samples first, then average their angles.
    nearby_samples.sort()
    samples_to_use = min(NEIGHBOR_COUNT, len(nearby_samples))
    angle_total = 0
    for index in range(samples_to_use):
        angle_total += nearby_samples[index][1]

    return round(angle_total / samples_to_use)

async def main():
    training_samples = []
    training_mode = True
    was_above_threshold = False

    # Move to absolute 0° before the first training sample.
    await motor.run_to_absolute_position(port.E, 0, RETURN_SPEED)
    print("Training mode: apply more than 6 N to save a sample.")

    while True:
        # Either arrow button changes modes. Wait for release so one press
        # cannot immediately switch back again.
        if button.pressed(button.LEFT) or button.pressed(button.RIGHT):
            if training_mode and not training_samples:
                print("Save at least one sample before prediction mode.")
            else:
                training_mode = not training_mode

                if training_mode:
                    print("Training mode: existing samples are kept.")
                else:
                    print("Prediction mode. Samples:", training_samples)

            while button.pressed(button.LEFT) or button.pressed(button.RIGHT):
                await runloop.sleep_ms(20)

            # Require a fresh force press when entering training mode.
            was_above_threshold = (
                force_sensor.force(port.B) > FORCE_THRESHOLD
            )

        if training_mode:
            # Save once when force crosses above 60 decinewtons.
            is_above_threshold = force_sensor.force(port.B) > FORCE_THRESHOLD

            if is_above_threshold and not was_above_threshold:
                distance_mm = distance_sensor.distance(port.C)

                # Do not save a sample without a valid distance reading.
                if distance_mm != -1:
                    motor_degrees = motor.absolute_position(port.E)
                    training_samples.append((distance_mm, motor_degrees))
                    print("Saved:", distance_mm, "mm,",
                          motor_degrees, "degrees")

                    # Return to absolute 0° after saving.
                    await motor.run_to_absolute_position(
                        port.E, 0, RETURN_SPEED
                    )
                else:
                    print("No valid distance. Move over an object and try again.")

            was_above_threshold = is_above_threshold

        else:
            # Predict an angle from the closest saved distances.
            distance_mm = distance_sensor.distance(port.C)

            if distance_mm != -1:
                predicted_angle = predict_motor_position(
                    distance_mm, training_samples
                )

                # Move only when more than 3° away from the target.
                if abs(motor.absolute_position(port.E) - predicted_angle) > 3:
                    print("Distance:", distance_mm, "mm; predicted angle:",
                          predicted_angle, "degrees")
                    await motor.run_to_absolute_position(
                        port.E, predicted_angle, PREDICTION_SPEED
                    )

        # Give the buttons and sensors time to update.
        await runloop.sleep_ms(20)

runloop.run(main())
